# tx-v2 Starter Template

This template is the smallest useful bot shape: one decorated feature class, dev storage, and the same doctor/start flow as the full repo.

```bash
bun install
cp .env.example .env
bun run doctor
bun run dev
```

Edit `src/features/hello.ts` first. Add more feature classes beside it, then add them to the `features` array in `src/index.ts`.
